# Estudo Biomédico

Aplicativo científico interativo de visualização biomédica para estudo de:

- interação entre macrófago alveolar e _Mycobacterium tuberculosis_;
- cascata TLR2–MyD88–NF-κB–CYP27B1–VDR–CAMP–LL-37;
- apresentação antigênica por MHC-II;
- enzimas, organelas e partículas;
- hierarquia anatômica de pulmão a DNA bacteriano;
- sistemas CRISPR tipo III-A em representação conceitual.

> Conteúdo educacional; não representa orientação clínica ou diagnóstica.

## Executar

```bash
npm install
npm run dev
```
